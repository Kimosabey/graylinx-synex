# 7. Feature Domains in Detail

This section expands the platform from architecture into concrete user-facing features. Each feature is described by purpose, actors, inputs, workflow, example and expected outcome. The three P0 pillars remain the priority: Reports, Work Orders and Synex Copilot.

## 7.1 Feature map

| **Priority** | **Feature domain** | **Core features** | **Primary outcome** |
|---|---|---|---|
| **P0** | Reports | Dashboards, KPI reports, open more detail, scheduled reports, ad-hoc analysis, AI narrative, exports, comparisons | Understand what is happening |
| **P0** | Work Orders | Create, prioritize, approve, assign, execute, parts, findings, verification, close/reopen | Get work done correctly |
| **P0** | Synex Copilot | Ask, explain, investigate, recommend, draft, execute, verify, report, escalate | Turn questions into controlled action |
| **P0** | Control Plane | Identity, scope, rule, risk, approval, safety, evidence, audit | Make AI safe and controllable |
| **P1** | Asset Intelligence | Hierarchy, health, history, dependencies, criticality, digital context | Understand every asset |
| **P1** | Reliability / FDD | Fault detection, diagnosis support, evidence, bad actors, trends | Find and explain problems |
| **P1** | Knowledge / RAG | SOPs, manuals, cases, WOs, source-aware retrieval | Give grounded answers |
| **P1** | Maintenance Planning | Prioritization, scheduling, technician/parts matching, windows | Choose the right work at the right time |
| **P1** | Inventory / Procurement | Parts availability, reservation, shortage, reorder/PO suggestions | Remove execution blockers |
| **P1** | Alerts / Escalation | Thresholds, FDD events, SLA breaches, risk escalation | Get attention at the right time |
| **P1** | Verification / Learning | Post-work validation, reopen, outcome capture, lessons | Prove the fix and improve |
| **P2** | Advanced AI | Voice, vision, optimization, deeper autonomy where justified | Extend feature after core loop is reliable |
