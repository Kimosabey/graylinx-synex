# 21. Role-Based Examples

| **User** | **Example question** | **Main experience** |
|---|---|---|
| Executive | “What are the biggest risks?” | Short business summary + drill-down |
| Plant Manager | “What needs attention now?” | Prioritized equipment/work list |
| Maintenance Manager | “Why is backlog high?” | WO blockers + actions |
| Reliability Engineer | “Why did FDD trigger?” | ML/FDD evidence + similar cases |
| Planner | “What can we schedule tomorrow?” | WO + people + parts + time window |
| Technician | “What do I check first?” | WO + SOP + safety + history |
| EHS | “Is this action allowed?” | Safety/rule/approval result |
| Customer | “How is my site?” | Customer-scoped report and explanation |
| Admin | “Why can't this user access it?” | Permission/configuration explanation |
