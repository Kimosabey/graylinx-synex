# 24. Delivery Priorities and Roadmap

| **Phase** | **Build first** | **Reason** |
|---|---|---|
| **P0.1** | Reports foundation + KPI/lineage + role scope | Core visibility |
| **P0.2** | WO lifecycle + state machine + approvals | Core execution |
| **P0.3** | Synex Copilot read/analyze/report | Fastest broad user value |
| **P0.4** | Copilot → governed WO draft/create | Close intelligence-to-action loop |
| **P0.5** | FDD → evidence → suggestion → WO | Predictive maintenance loop |
| **P0.6** | Post-work verification → reopen/close | Prove outcomes |
| **P1** | Planning + inventory + vendor + alerts | Operational depth |
| **P1** | Advanced RAG/knowledge workflows | Better grounded assistance |
| **P2** | Voice/vision/advanced autonomy | Only after core controls and outcomes are proven |

| **NORTH-STAR: Every feature should answer one of four questions: What is happening? Why? What should we do? Did it work?** |
|---|
