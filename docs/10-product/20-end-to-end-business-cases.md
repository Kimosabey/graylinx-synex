# 20. End-to-End Business Cases

| **Case** | **Actors** | **End-to-end flow** | **Success measure** |
|---|---|---|---|
| **Executive risk review** | Executive + Copilot | Ask → report → open more detail → top risks → actions | Decision time reduced |
| **Plant health review** | Plant Manager + Reliability | Dashboard → bad actors → evidence → action plan | Risk/backlog reduced |
| **Predictive maintenance** | FDD + Reliability + Maintenance | Detect → diagnose → WO → repair → verify | Failure/downtime avoided |
| **Technician guided repair** | Technician + Copilot | WO → safety → SOP → parts → repair → verify | MTTR / first-time-fix |
| **Customer monthly review** | Customer + Service | Report → explain → open more detail → actions | Customer transparency |
| **Critical safety issue** | EHS + Maintenance | Alert → block → human review → permit → controlled work | No unsafe execution |
| **Repeated failure** | Reliability + Maintenance | Pattern detection → case comparison → corrective action → verification | Repeat failure reduction |
| **Bad data** | Data/IoT + Reliability | Quality fail → NO_DIAGNOSIS → data action → recheck | False diagnosis reduction |
| AI rule incident | Security/Governance | Detect → contain → audit → investigate → rollback | Incident MTTR |
