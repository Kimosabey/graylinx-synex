# 35. Priority Workflows

## 35.1 Report → Insight → Action

REPORT → USER QUESTION → COPILOT → AUTHORIZATION → ANALYSIS → EVIDENCE → RECOMMENDATION → WO / ESCALATION

## 35.2 Fault → Fix → Proof

ML/FDD → EVIDENCE → DIAGNOSIS → AI EXPLANATION → MAINTENANCE RECOMMENDATION → WO → TECHNICIAN → POST-WORK DATA → VERIFICATION → PASS/CLOSE or FAIL/REOPEN

## 35.3 Technician workflow

MY WORK → OPEN WO → AI EXPLAINS → SAFETY → SOP/CHECKLIST → PARTS → EXECUTE → FINDINGS → REPAIR → COMPLETE → VERIFY

## 35.4 Executive workflow

ASK → ENTERPRISE SCOPE → KPI REPORT → DRILL-DOWN → TOP RISKS → ACTIONS → OUTCOME / ROI

## 35.5 Unallowed workflow

REQUEST → IDENTITY/SCOPE → DENY → NO DATA / NO SIDE EFFECT → AUDIT → OPTIONAL ESCALATION

## 35.6 Bad-data workflow

DATA QUALITY FAIL → NO_DIAGNOSIS → EXPLAIN LIMITATION → INSTRUMENTATION/DATA-QUALITY ACTION → RECHECK
