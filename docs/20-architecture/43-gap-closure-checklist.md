# 43. Gap Closure Checklist

The following items were identified in cross-functional critique and are now explicitly represented in the target architecture.

| **Gap** | **10/10 treatment** |
|---|---|
| **ROI** | Business KPI/ROI model |
| **Production context** | Operational/production impact considered in prioritization |
| **Technician UX** | Dedicated technician job execution workflow |
| **Evidence** | Formal evidence-pack contract |
| **Model/agent registry** | Explicit registry fields and lifecycle |
| **Security** | Threat classes + controls + tool-side enforcement |
| **Compliance** | Control/evidence mapping approach |
| **Safety** | Safety action category matrix |
| **Data** | Data product contract + lineage |
| **Capability matrix** | Persona → feature → data → agent → tool → approval → outcome |
| **State machine** | WO, approval, agent, tool and verification states |
| **Concurrency** | Idempotency + optimistic locking/state checks |
| **Report security** | Scope, export and scheduled-job reauthorization |
| **Prompt injection** | Input/content threat controls |
| **Credential security** | Credential broker/scoped identity |
| **Break-glass** | Temporary, audited emergency elevation |
| **Policy versioning** | Versioned rules + simulation |
| **Evaluation** | validation + release gates |
| **Resilience** | RTO/RPO + degraded mode/offline modes |
| **Observability** | Agent/tool/model/RAG/action/business service targets |
